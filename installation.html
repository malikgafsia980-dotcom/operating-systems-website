Guide d'Installation des OS

Installation de Windows

Prérequis : Clé USB (8 Go), image ISO de Windows, licence.

  1. Télécharger Media Creation Tool depuis le site de Microsoft.
  2. Créer une clé USB bootable.
  3. Redémarrer et accéder au BIOS (F2 ou Suppr).
  4. Booter sur la clé USB.
  5. Suivre les instructions à l'écran.
Télécharger Windows

Installation de Linux (Ubuntu)

Prérequis : Clé USB (4 Go), image ISO d'Ubuntu.

  1. Télécharger l'ISO depuis ubuntu.com.
  2. Créer une clé USB bootable avec Rufus ou Etcher.
  3. Redémarrer et booter sur la clé.
  4. Choisir 'Installer Ubuntu'.
  5. Suivre les instructions et redémarrer.

Systèmes embarqués : installation et mise à jour

Contrairement à un ordinateur classique, un OS embarqué est généralement installé par le fabricant sur l'appareil. L'utilisateur ne l'installe pas toujours lui-même.

  1. Le fabricant choisit un OS adapté au matériel et à la fonction de l'appareil.
  2. Le logiciel est chargé dans une mémoire intégrée, par exemple une mémoire flash.
  3. Les mises à jour sont fournies par le fabricant, parfois par USB ou par Internet (OTA).
  4. Dans une voiture, il faut utiliser les procédures et outils officiels : une mauvaise mise à jour peut empêcher un équipement de fonctionner.

Exemple : l'écran multimédia d'une voiture peut recevoir une mise à jour logicielle, tandis que les calculateurs du moteur et des freins sont entretenus selon des procédures spécialisées.

Installation de macOS

Prérequis : Mac compatible, connexion Internet, compte Apple.

  1. Ouvrir Préférences Système > Mise à jour.
  2. Télécharger la dernière version de macOS.
  3. Lancer l'installateur.
  4. Suivre les instructions et redémarrer.
