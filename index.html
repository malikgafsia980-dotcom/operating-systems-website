Les Systèmes d'operations

Introduction

Un système d'exploitation (OS) est un logiciel qui gère le matériel et les logiciels d'un ordinateur. Il sert d'intermédiaire entre l'utilisateur et le matériel.

Les plus connus sont Windows, macOS, Linux, Android et iOS.

Les Principaux OS

Windows

Le plus utilisé sur PC.

Linux

Open source et gratuit.

macOS

Système d'Apple pour Mac.

Android

OS mobile de Google.

Les OS Embarqués

Un OS embarqué est intégré dans un appareil pour gérer des fonctions précises. On en trouve dans les voitures, les appareils ménagers, les objets connectés et les machines industrielles.

Voitures

Moteur, ABS et airbags.

Maison connectée

Téléviseurs, montres et électroménager.

Industrie

Robots, capteurs et machines.

Utilisation par Appareil

PC / Laptop

Windows, macOS, Linux

Smartphone

Android, iOS

Serveur

Linux Server, Windows Server

Pourquoi Installer un OS ?

L'installation d'un OS est nécessaire pour utiliser un ordinateur et configurer l'environnement de travail.
